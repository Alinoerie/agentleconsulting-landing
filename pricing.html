Pricing questions

What do AI agents actually cost to run?

Agent running costs are passed through at cost. You see exactly what the technology costs. Text agents typically run ~$150/month for basic API usage. Voice agents run ~$15–30/min of call time. We don't mark these up.

What's the difference between the tiers?

Advisory is a monthly retainer for ongoing consulting access. Cancel any time. So you can see exactly what you'd be building before committing. Execution is the full build: we create 3–5 production workflows end-to-end.

Is Pay As You Go right for me?

Execution clients often convert to Pay As You Go within 60–90 days. Once workflows are live, you realise the maintenance burden. Platform API updates, new integrations, workflow tweaks. Pay As You Go covers custom scope with no minimum commitment. Billed by project or time-and-materials.

Do I own the workflows?

Yes. 100%. On Advisory you own the roadmap. On Execution and Pay As You Go you own every workflow we build. We don't hold them hostage. You can host them yourself, export them, or let us manage them.

Can I pay in installments?

Execution requires a 6-month commitment. Pay As You Go is billed by project or time-and-materials. Discover is a single one-time payment.
