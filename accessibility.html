Accessibility Statement

AgentleConsulting is committed to ensuring digital accessibility for people with disabilities.

Our Commitment

We believe that accessibility is not a feature — it is a civil right. We are committed to providing a website that is accessible to the widest possible audience, regardless of ability.

This statement was last reviewed on 17 May 2026.

Accessibility Standards We Follow

Our website aims to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. These guidelines explain how to make web content more accessible for people with disabilities and more user-friendly for everyone.

We also take the European Accessibility Act (EAA) into account, which requires digital products and services to be accessible to people with disabilities.

Measures We Have Taken

  • All pages include a skip-to-content link for keyboard users
  • All images include descriptive alt text
  • All form inputs have associated visible or programmatic labels
  • Color contrast ratios meet WCAG AA standards (minimum 4.5:1 for normal text)
  • All interactive elements are keyboard navigable
  • Focus indicators are visible on all interactive elements
  • Text resizes correctly up to 200% without loss of content
  • Page layouts use semantic HTML (headings, landmarks, lists)
  • Motion and animations respect prefers-reduced-motion
  • Our forms include error identification and suggested corrections

Known Limitations

While we strive for full accessibility, you may encounter some limitations:

  • Some older third-party integrations (e.g., Calendly embeds) may not be fully controllable by our accessibility standards — these are provided by external services
  • Client logos on the homepage are currently placeholder images — these will be updated with proper alt text when final logos are provided

Technical Information

This website is built using semantic HTML5, CSS3, and vanilla JavaScript. It is hosted on Vercel and built with static files for maximum performance and reliability.

Accessibility-related features implemented:

  • role and aria-* attributes on dynamic components
  • prefers-reduced-motion media query to disable animations
  • prefers-color-scheme support for light/dark preferences (future enhancement)
  • Explicit width and height attributes on images to reduce layout shift
  • loading="lazy" on below-fold images

Assessment Approach

We conduct regular accessibility audits using a combination of:

  • Automated testing tools (axe DevTools, WAVE)
  • Manual keyboard navigation testing
  • Screen reader testing (NVDA, VoiceOver)
  • Color contrast analysis
